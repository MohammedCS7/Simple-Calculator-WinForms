# 🧮 C# Windows Forms Simple Calculator

A desktop calculator application built using **C#** and **.NET Windows Forms**. This project demonstrates the transition from C++ console application logic to event-driven Graphical User Interface (GUI) programming in .NET.

---

## 🌟 Key Features

- **Core Operations:** Addition, Subtraction, Multiplication, and Division.
- **State Guarding & Defensive Parsing:** Utilizes `double.TryParse` to gracefully handle input validations and prevent application crashes.
- **Chain Operations & Continuous Logic:** Seamlessly handles multi-step operations without requiring user reset.
- **Decimal & Backspace Support:** Includes guard clauses to prevent duplicate decimals and allows single-character backspacing.
- **Theme Switching (Dark / Light Mode):** Dynamic runtime UI background and foreground color toggling.

---

## 🛠️ Tech Stack & Concepts

- **Language:** C#
- **Framework:** .NET Framework / Windows Forms (WinForms)
- **Concepts Applied:**
  - Control Event Handling
  - Enumerations (`enum`) & Static Helper Methods
  - UI State Management
  - Defensive Programming (`double.TryParse`)

1. Clone the repository:
   ```bash

   ```
